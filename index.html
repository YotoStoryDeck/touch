📋 Quick Setup Guide
  • 1
    Connect USB-C Cable

    Plug a USB-C data cable between your computer and the Waveshare ESP32-S3 board. Ensure the cable supports data transfer (not charge-only).

  • 2
    Open in Chrome or Edge

    Click the orange Connect & Install button above and grant serial port permission when prompted.

  • 3
    Confirm Erase & Flash

    Select Erase device and click Next. The browser will flash the bootloader, partition table, and firmware in under 60 seconds.

  • 4
    First Boot & Wi-Fi Pairing

    When flashing finishes, the 800×480 screen will light up. Join Wi-Fi "StoryDeck-Setup" to pair with StoryDeck Core or Standalone Cloud.

❓ Troubleshooting & Tips
No Serial Port Detected / Board Not Showing in Chrome
  1. Force ROM Bootloader: Unplug the board. Hold down the physical BOOT button on the back of the Waveshare PCB, plug the USB-C cable in, and release the BOOT button.
  2. Check Your Cable: Many USB cables bundled with toys or vape chargers are power-only. Test with a known data cable (e.g. phone sync cable).
  3. Driver Check (Windows): If Windows shows Unknown Device, install the standard CP210x or CH34x driver or Espressif USB JTAG driver.
Linux / Ubuntu: Permission Denied on /dev/ttyACM0
On Linux, your user account must belong to the dialout group to access serial ports: 
sudo usermod -a -G dialout $USER
Log out and back in, then refresh this page.
MicroSD Card Compatibility & Formatting
MicroSD cards must be formatted as FAT32 (exFAT is not supported by the ESP32 SPI driver). For cards 64GB or larger, format with GUIFormat or Rufus selecting Large FAT32 with 32KB cluster size.
Can I Flash Manually via PlatformIO or CLI?
Yes! Clone the repository and compile using PlatformIO: 
git clone https://github.com/YotoStoryDeck/touch.git
cd touch
pio run -e waveshare-s3-43b -t upload
